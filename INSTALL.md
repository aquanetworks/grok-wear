# Установка Grok Wear (VPN на часах)

Приложение ставится **напрямую на часы** (Samsung Galaxy Watch Ultra, Wear OS, только 32-bit `armeabi-v7a`). Телефон для работы Grok и VPN не нужен. Корня, Shizuku и системного VPN нет.

**APK:** `grok-wear-vless-armeabi-v7a.apk` (~64 МБ из‑за встроенного mihomo `armeabi-v7a`). Подпись — сгенерированный ключ, см. [Подпись](#подпись-apk) ниже.

> Неофициальный клиент Grok. API может измениться или сломаться. Подписку VPN в репозиторий не кладите.

## 1. Режим разработчика на часах

1. **Настройки → О часах → Сведения о ПО** (или **Программы**).
2. Нажмите **Номер сборки** (Software version) **семь раз**. Появится «Вы стали разработчиком».
3. **Настройки → Параметры разработчика**:
   - включите **Отладка по ADB**;
   - включите **Отладка по Wi‑Fi** / **Беспроводная отладка**;
   - при запросе — **Всегда разрешать в этой сети**.

Оставьте экран часов включённым: в сон Wi‑Fi часто гаснет и установка обрывается.

## 2. Установка через WearLoad (телефон)

WearLoad (и похожие: Wear Installer 2, Bugjaeger) ставит APK по беспроводному ADB. Приложения сторонние, к этому проекту не относятся.

1. Поставьте WearLoad на телефон в той же Wi‑Fi сети, что и часы (или раздайте точку с телефона и подключите часы к ней).
2. На часах откройте **Беспроводная отладка** и **Сопряжение с устройством**. Запомните IP, порт сопряжения и **шестизначный код**.
3. В WearLoad: сопряжение с часами (IP:порт + код).
4. После сопряжения подключитесь к **рабочему** порту ADB (он другой, чем порт сопряжения; смотрите его вверху экрана беспроводной отладки).
5. Выберите APK `grok-wear-vless-armeabi-v7a.apk` и установите. Дождитесь **Success**.
6. Если стоит старая Grok Wear с **другой** подписью: сначала удалите её (`si.zya.grokwear`) — вход в Grok на часах сбросится.

## 3. Установка с компьютера (ADB Wi‑Fi)

С компьютера в той же сети:

```sh
adb pair <IP>:<порт-сопряжения>
# введите шестизначный код
adb connect <IP>:<рабочий-порт>
adb devices
adb install -r --no-streaming grok-wear-vless-armeabi-v7a.apk
```

`--no-streaming` надёжнее на часовом Wi‑Fi. Если `INSTALL_FAILED_UPDATE_INCOMPATIBLE` — `adb uninstall si.zya.grokwear` и снова install.

Подробности по ADB: [docs/INSTALL.md](docs/INSTALL.md) (английский, без VPN).

## 4. Назначить ассистентом (долгое нажатие Home)

Чтобы вызывать Grok долгим нажатием **Home** на Galaxy Watch:

1. Откройте **Grok Wear** на часах, войдите в аккаунт (после VPN, шаг 5).
2. В приложении: **Настройки → Assistant button: On** (или экран после первого входа).
3. Часы откроют системный выбор цифрового ассистента. Выберите **Grok Wear**.
4. «Hey Google» и штатный ассистент после этого не отвечают, пока не выберете другой ассистент в настройках часов.

Микрофон в фоне не слушает: открывается только после Talk / кнопки ассистента.

## 5. Подписка VPN на часах

1. Откройте **Grok Wear** → **VPN settings** (с экрана входа) или **Настройки → VPN**.
2. **Import subscription**. Введите **HTTPS**-ссылку подписки v2RayTun (клавиатура / диктовка Wear), либо вставьте Clash YAML / список `vless://`.
3. Дождитесь списка серверов. Выберите узел **VLESS + Reality**.
4. **Connect**. Индикатор должен стать зелёным («Connected»). **Test latency** — проверка через туннель (`generate_204`).
5. Ссылка подписки хранится зашифрованной (Android Keystore). Прямой выход на Grok при выключенном VPN **запрещён**.

Не отправляйте никому свою ссылку подписки и не коммитьте её.

## 6. Разговор с Grok без телефона

1. Часы в Wi‑Fi или LTE, VPN **Connected**.
2. **Sign in**: QR-код, подтверждение в браузере телефона (только для входа; дальше телефон не нужен).
3. Выберите бота → **Talk**. Разрешите микрофон.
4. Говорите; ответ идёт в динамик часов или Bluetooth-гарнитуру.
5. Долгое Home вызывает основного бота, если Grok Wear — цифровой ассистент.

## Если не подключается

- **«VPN is off»** — сначала Connect в VPN settings. Grok намеренно не ходит в обход.
- Подписка не читается — это должен быть Clash YAML, base64-список URI или `vless://`. HTTP (не HTTPS) ссылки отвергаются.
- Connect падает сразу — нет `libmihomo.so` или OEM запретил `exec` из `nativeLibraryDir`. Смотрите README, раздел «не проверено».
- Сеть часов мёртвая после чужого системного прокси: этот APK **не** пишет `settings http_proxy`. Если раньше стоял mihomo-watch-proxy + Shizuku, снимите глобальный прокси по ADB:  
  `adb shell settings delete global http_proxy`

После установки беспроводную отладку лучше выключить — она сажает батарею.

## Подпись APK

Сборка агента подписана сгенерированным ключом (не Play Store). Файл ключа **не** в git (`*.jks` в `.gitignore`).

Типичная генерация:

```sh
keytool -genkeypair -keystore grok-wear-release.jks -alias grokwear \
  -keyalg RSA -keysize 2048 -validity 10950 \
  -storepass grokwear-sideload -keypass grokwear-sideload \
  -dname "CN=Grok Wear sideload, O=aquanetworks, C=US"
```

`keystore.properties` (тоже не коммитится):

```properties
storeFile=/path/to/grok-wear-release.jks
storePassword=grokwear-sideload
keyAlias=grokwear
keyPassword=grokwear-sideload
```

Обновления поверх этой установки требуют **тот же** ключ. Иначе сначала uninstall.
